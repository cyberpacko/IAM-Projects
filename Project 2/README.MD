
# Project 2: Cloud RBAC Model & Access Governance

## Overview
This project designs a scalable RBAC model for Azure, including custom roles, least privilege access, and automated access reviews to maintain governance across cloud resources.

## Business Problem
Unstructured access models lead to privilege creep, excessive permissions, and audit failures. Organizations need a standardized RBAC framework to enforce least privilege.

## Objectives
- Build a role-based access model aligned with job functions

- Implement least privilege using custom roles

- Automate access reviews for ongoing governance
